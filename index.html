Five questions before adopting any AI tool

  1. Which task will it replace, and how long does that task take today?
  2. Can you test it on five questions whose answers you already know?
  3. Does it show its sources, and do the sources support the claims?
  4. Where does your data go, and how long is it kept?
  5. What does it cost per completed task, checked on the vendor’s own page today?
