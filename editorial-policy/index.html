Editorial Policy

How we decide what to publish and how we fix what we get wrong.

Starting template. Edit this policy so that it describes your newsroom’s real practice before publication.

Sourcing

We link primary sources wherever they exist. When we rely on a secondary report, we say so and link to it. We do not cite sources we have not opened.

Verification

Statistics, quotations, dates, prices and names are checked against the source before publication. If a claim cannot be verified, we leave it out or label it as unverified.

Numbers and quotations

We never invent figures, quotations or findings. Prices change often, so we link to the vendor’s own page and note the date we checked.

Corrections and updates

When we find an error, we correct it in the article, state what changed and show the update date. Send corrections to editor@theparameter.example.
